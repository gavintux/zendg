# 苦集滅道

## 領域專家解釋
**苦集滅道**即佛教最核心的基礎教義框架——「四聖諦」（Four Noble Truths），是佛陀初轉法輪時提出的一套完整診斷與療癒生命困境的系統方法論：
1. **苦諦（現狀診斷）**：直面生命的無常與不圓滿本質（如生老病死、求不得、愛別離等），承認執著必然伴隨痛苦。
2. **集諦（歸因分析）**：剖析痛苦的成因——源於「[[02領域/量子/心經/無明\|無明]]」與渴愛執取，使煩惱與業力不斷「招集」累積。
3. **滅諦（目標狀態）**：指出痛苦是可以徹底止息的，即斷除執著後所達致的[[02領域/量子/心經/涅槃\|涅槃]]解脫之境。
4. **道諦（實踐路徑）**：提供從苦走向滅的具體方法論，如「八正道」（正見、正思惟、正語、正業、正命、正精進、正念、正定）。

在[[02領域/量子/心經/00心經本文\|00心經本文]]中說「無苦集滅道」，並非否定四聖諦的實修價值，而是站在[[02領域/量子/心經/諸法空相\|諸法空相]]的高度，提醒修行者不可將教法本身當成僵化實有的教條——四聖諦是渡河的木筏，既要善用其渡河，到達彼岸後亦不應扛著木筏不放。

## 範例說明
* **如同現代醫學診療邏輯**：
  * **苦**＝確診症狀；
  * **集**＝找到病因；
  * **滅**＝確認康復的可能性；
  * **道**＝開立處方與復健計畫。
* **般若視角的邊界提醒**：當身體已經康復（覺悟空性）時，不再需要執著於「病症」與「藥方」的對立標籤，這正是「無苦集滅道」的解脫精神。
