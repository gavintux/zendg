# 量子計算與多世界詮釋

本頁面整合量子力學測量問題的兩大重要理論支柱——**多世界詮釋 (Many-Worlds Interpretation)** 與**量子去相干 (Quantum Decoherence)**，並說明量子疊加與糾纏如何驅動**量子電腦 (Quantum Computer)** 的演算法突破、資安衝擊與硬體挑戰。

---

## 1. 測量問題與多世界詮釋 (Many-Worlds Interpretation)

### 1.1 薛丁格的貓與「月亮問題」
在 [[wiki/量子力學基礎與核心現象\|量子力學基礎與核心現象]] 中，微觀粒子在未被測量前處於多種可能狀態的**疊加態 (Superposition)**。愛因斯坦曾質疑：「難道只有當你看著月亮時，月亮才在那裡嗎？」薛丁格 (Erwin Schrödinger) 更提出「**薛丁格的貓**」思想實驗，藉著「箱內放射性原子衰變與否導致貓處於既死又活的疊加態」來反諷量子機率詮釋的不完備。

### 1.2 艾弗雷特三世的多世界詮釋 (MWI)
1957 年，美國普林斯頓大學博士生**艾弗雷特三世 (Hugh Everett III)** 提出截然不同的解方：
* **宇宙波函數 (Universal Wave Function)**：整個宇宙都由單一的波函數依照量子力學方程式演化，測量時波函數**並不會崩潰**。
* **分岔的平行歷史**：當測量發生時（例如打開箱子觀察貓），被測系統、測量儀器與觀察者會在交互作用下彼此連動，使宇宙波函數分岔為不同分支——在一個分支裡「原子衰變、毒藥打破、貓死、觀察者看到死貓」；在另一個分支裡「原子未衰變、貓活著、觀察者看到活貓」。
* **平行世界互不干擾**：每一次測量或量子選擇都會分支出獨立的平行歷史（此理論後來成為電影《天能 (Tenet)》等作品的高維穿梭靈感）。各分支皆真實存在，彼此間無法溝通或交換資訊。該理論直到 1970 年代才逐漸受到物理學界重視，但現今科技尚無法直接實驗驗證。

## 2. 量子去相干 / 退相干 (Quantum Decoherence)

**量子去相干**（工程領域常稱**量子退相干**）從物理交互作用的角度，解釋了為何微觀有疊加態、巨觀世界卻沒有「既死又活的貓」：

* **相干性的喪失**：在雙狹縫實驗中，兩道狹縫的波必須維持「相干性」才能產生干涉條紋；只要加入偵測器與粒子互動，相干性就會被破壞，干涉條紋隨之消失。
* **環境交互作用與平衡**：量子系統一旦沒有完全孤立、與外在環境交換資訊或能量（好比熱水與冷水倒入同一杯中交互作用最終達到溫水平衡），原本各自的波函數就會與環境混雜，逐漸喪失量子疊加特性。
* **解答愛因斯坦與薛丁格的質疑**：現實中的月亮與貓由海量原子構成，時時刻刻與空氣、光子及周遭環境發生交互作用，量子去相干幾乎在瞬間完成。因此巨觀物體早已不是孤立量子系統，月亮一直都在那裡，貓也不可能同時既生又死。

## 3. 量子電腦運作原理與算力革命

傳統電腦透過二進位**位元 (Bits)** 進行線性且單向的運算（非 0 即 1）；量子電腦則改採**量子位元 (Qubits)**，利用量子疊加與糾纏特性，在同一時間對多種狀態進行平行運算。

### 3.1 量子閘與平行計算
* 傳統電腦透過邏輯閘處理 0 與 1；量子電腦則使用**量子閘 (Quantum Gates)** 操縱量子位元的狀態，例如 **Hadamard 閘** 可將量子位元轉變為 0 與 1 的疊加態，進而執行平行計算。
* **指數級加速潛力**：面對特定極高複雜度的問題（傳統電腦可能需耗時 330 年甚至數千萬年），量子電腦有機會縮短至數分鐘甚至數秒完成。

### 3.2 國際量子競賽與里程碑
* **Google**：2023 年展示量子電腦 `Sycamore` 能在數秒內完成傳統頂尖超級電腦 `Frontier` 推估需時約 **47 年** 才能完成的特定運算任務。
* **IBM**：持續擴展量子位元規模，已推出超過 **1,000 個量子位元** 的系統，並規劃邁向 **4,000 個以上量子位元**。
* **臺灣布局**：台灣亦組成「量子國家隊」，積極投入量子計算硬體與演算法研發。

### 3.3 兩大經典量子演算法

| 演算法名稱 | 核心用途 | 算力優勢與衝擊 |
| :--- | :--- | :--- |
| **Grover 演算法** | 無序資料庫搜尋 | 將搜尋時間複雜度從傳統電腦的 $O(N)$ 加速至 **$O(\sqrt{N})$**，大幅縮短海量資料檢索時間。 |
| **Shor 演算法** | 大數質因數分解 | 傳統電腦需數千萬年才能破解的質因數分解問題，量子電腦可在極短時間內求解，直接威脅現今網路廣泛採用的 **RSA 加密技術**，引發全球加速研發**後量子密碼學 (Post-Quantum Cryptography, PQC)**。 |

## 4. 工程瓶頸與未來應用展望

* **最大技術挑戰——量子退相干與材料限制**：量子位元必須處於極度隔絕環境干擾的狀態下才能維持疊加態；微小雜訊就會引發退相干並導致運算錯誤，量子位元數量越多，維持整體穩定的難度越高。目前科學界正透過超導體與半導體材料等路線尋求突破（相關運算結構亦可對照 [[wiki/AI_與學習科技\|AI_與學習科技]] 的算力基礎架構演進）。
* **核心應用前景**：量子電腦並非要取代日常個人電腦，而是專門解決傳統電腦難以處理的複雜系統模擬與最佳化問題，涵蓋：
  * **科學與醫療**：藥物分子設計、新材料開發、天文物理模擬。
  * **產業與環境**：氣候變遷模型預測、金融風險分析、交通運輸與物流最佳化。
  * **資訊安全**：迫使全球金融與網路基礎設施全面升級至抗量子攻擊的後量子密碼體系。
