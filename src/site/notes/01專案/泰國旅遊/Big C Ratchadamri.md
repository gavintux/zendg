# Big C Ratchadamri

**Big C Supercenter Ratchadamri** 位於曼谷市中心拉差丹利路、[[01專案/泰國旅遊/CentralWorld 晚餐\|CentralWorld 晚餐]] 正對面，是觀光客採買泰國伴手禮的一站式聖地。賣場空間寬敞、熱門商品備貨極為齊全且營業至深夜 24:00，幾乎是每個台灣家庭來曼谷的必排採買點。

## 必買伴手禮清單參考
* **經典零食**：小老闆海苔（大包裝／捲狀）、大哥豆花生、Bento 超味魷魚片、Pocky 芒果／香蕉限定版、皇家蜂蜜條與牛乳片、泰國限定口味洋芋片（打拋豬、烤海苔、鹹蛋黃）、榴槤乾／芒果乾。
* **飲品與調味**：手標泰奶（ChaTraMue）茶葉與三合一沖泡包、藍象／MAMA 冬蔭功泡麵與泰式調理包。
* **日常好物**：薄荷鼻通（Poy-Sian）、蛇牌涼感爽身粉、青草膏與各式香氛皂。

## 採買、退稅與動線 Tips
* **滿額辦理退稅（VAT Refund）**：單日消費滿 **2,000 泰銖**，結帳後記得持收據與**護照正本**前往賣場客服櫃台填寫退稅黃單（P.P.10），離境當日在[[01專案/泰國旅遊/素萬那普機場\|素萬那普機場]]托運前蓋海關章即可退稅。
* **自備大型購物袋／登機箱**：泰國賣場不免費提供塑膠袋，建議自備大型防潑水環保袋（現場亦可加購 Big C 耐用大編織袋）或直接推空箱前來裝貨。
* **超省力行程建議**：因就在 [[01專案/泰國旅遊/CentralWorld 晚餐\|CentralWorld 晚餐]] 對面（過天橋即達），強烈建議改在 **Day 5 晚餐後直接採買並搭車回[[01專案/泰國旅遊/曼谷暹羅商圈飯店\|曼谷暹羅商圈飯店]]**，免去 Day 6 從[[01專案/泰國旅遊/河濱夜市\|河濱夜市]]跨區折返的奔波。
