# True Alpha Hub

**True Alpha Hub** 是泰國電信龍頭 True Corporation 於[[01專案/泰國旅遊/曼谷暹羅商圈\|曼谷暹羅商圈]]核心地帶（Siam Square Soi 3）打造的新世代數位文化與創作者旗艦空間，定位為東南亞首座專為 Alpha 世代與 Z 世代設計的科技潮流遊樂場。

## 現場亮點與樓層特色
* **1F（Level Up）**：品牌概念空間與專屬 TrueCoffee 咖啡吧，提供限定特調飲品與新潮周邊。
* **2F（Go-Live Lab）**：專業直播與影音創作攝影棚，創作者可即時將影像投影至建築外牆的巨型立體 LED 螢幕，互動感極強。
* **3F–4F（Co-Play Pit / Big Create）**：結合電競遊戲、Podcast 錄音、3D 虛擬人像掃描、音樂與藝術共創的體驗區，對青少年與喜歡科技新鮮感的孩子極具吸引力。

## 造訪 Tips 與行程調度
* **絕佳地理位置**：就在暹羅廣場 3 巷，距離[[01專案/泰國旅遊/曼谷暹羅商圈飯店\|曼谷暹羅商圈飯店]]與 BTS Siam 站僅步行數分鐘，順道也能逛逛暹羅廣場周邊的曼谷潮流小店（如 Gentlewoman、Daddy and the Muscle Academy 等）。
* **動線優化建議**：在[[01專案/泰國旅遊/2027-02-03_02-09泰國旅遊\|2027-02-03_02-09泰國旅遊]]中，相較於排在緊湊的 Day 5，非常適合順勢調整到 **Day 4 下午**（剛入住暹羅商圈飯店後輕鬆散步前往），再銜接晚間的[[01專案/泰國旅遊/朱拉隆功夜市（Banthat Thong）\|朱拉隆功夜市（Banthat Thong）]]。
