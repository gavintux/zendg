# 欣梅爾

勇者一行人的人類**勇者**，打倒魔王的傳奇英雄，也是小隊的靈魂人物。

### 角色特質
1. **帥氣與自戀**：年輕時容貌俊秀且相當自戀，甚至熱衷於在各地留下自己的銅像。
2. **高尚品格**：待人謙虛、善良且堅毅，深刻影響身邊的夥伴。
3. **與芙莉蓮的羈絆**：幼年曾受芙莉蓮救助，長大後邀請她加入冒險。他的逝世是芙莉蓮理解人類情感的起點。
