# 薩古魯

**薩古魯·加吉·瓦蘇戴夫**（Sadhguru Jaggi Vasudev），印度當代瑜珈士、詩人、人道主義者，也是艾薩基金會（Isha Foundation）的創始人。

### 核心學說與哲學
1. **業力 (Karma) 的真相**：業力並非外部的「懲罰或獎賞」，而是自身有意識與無意識所累積的「記憶與習性網絡」。
2. **向內探尋**：主張所有外在的遭遇本質上都是向內探詢與自我覺察的邀請。
3. **有意識的生活**：命運非不可改變，透過提升自我覺察與「有意識的選擇」，個人可以從業力的習性框架中解脫，掌握自己的生命。
