# 費倫

人類**魔法使**，芙莉蓮的首席弟子。

### 角色特質
1. **身世**：因戰爭失去雙親成為孤兒，被僧侶海塔收養。海塔臨終前將其託付給芙莉蓮。
2. **天賦**：擁有驚人的魔法控制力與超凡天賦，以史上最年輕首席成績取得三級魔法使資格，後取得一級魔法使資格。
3. **個性**：溫和穩重但有時對修塔爾克相當嚴厲，在小隊中扮演實際上的照顧者與常識人角色。
