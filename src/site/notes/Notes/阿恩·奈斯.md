# 阿恩·奈斯

**阿恩·奈斯**（Arne Naess，1912－2009），挪威著名哲學家，**深層生態學 (Deep Ecology)** 的創始人。

### 生平與學術貢獻
1. **最年輕教授**：27 歲即成為奧斯陸大學哲學教授，為挪威二十世紀最著名的學術泰斗。
2. **隱居修行**：長期隱居於 Hallingskarvet 山脈的 Tvergastein 小木屋，在此發展出其個人的生態智慧體系——「生態智慧 T (Ecosophy T)」，並實踐與自然共生的極簡生活。
3. **開創深層生態學**：1973 年發表《淺層與深層，長期的生態運動：一個摘要》，挑戰以人類中心、技術修補為基礎的傳統環境運動，開創了形上學進路的整體論環境哲學。
