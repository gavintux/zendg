# 艾冉

勇者一行人的矮人族**戰士**。

### 角色特質
1. **性格**：沉默寡言、不苟言笑，但開口往往能直擊要點。
2. **肉體**：擁有超乎常理的強韌身軀，無懼物理傷害，揮舞雙手大斧。
3. **導師**：收修塔爾克為徒，傾囊相授戰鬥技巧，其言行深受修塔爾克尊敬。
