# 海塔

勇者一行人的人類**僧侶**，外號「酒肉僧侶」。

### 角色特質
1. **性格**：睿智風趣，雖然身為僧侶卻嗜酒、挑食且愛說謊。
2. **魔力**：魔力量以人類而言非常龐大，負責隊伍的治療與輔助。
3. **晚年**：隱居並收養了孤兒費倫，臨終前委託芙莉蓮教導費倫魔法，開啟了新的故事。
