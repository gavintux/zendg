# 修塔爾克

人類**戰士**，戰士艾冉的徒弟。

### 角色特質
1. **身世**：故鄉被魔族襲擊時唯一的倖存者，因而帶有自責與自卑的心理。
2. **實力**：雖然個性乖巧膽小，實則繼承了艾冉極度結實的肉體與能劈開山壁的驚人破壞力。
3. **性格**：單純善良、富責任感，極受小孩子與地方居民歡迎。
